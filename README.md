# 창업 와글 데모

같은 업종, 같은 단계였던 사람이 그때 뭘 골랐는지 보여주려고 만든 화면입니다.
업종과 단계로 방을 좁히고, 들어가서 질문 하나를 보면 답이 쌓여 있습니다 — 접은 사람 답도 똑같이 남습니다.
지금 쓰는 데이터는 전부 예시이고, 여기서 쓴 글은 이 브라우저에만 남습니다.

## 이게 뭔가요

창업 와글 커뮤니티가 실제로 어떻게 도는지 보여주는 데모입니다. `#/rooms`에서 업종 × 단계로 방을 좁히고, 방에 들어가 질문을 고르면 같은 조건이던 사람들의 답이 조건별로 정리되어 보입니다. 질문을 올리고 답을 남기는 것도 실제로 동작합니다 — 쓴 글은 그 자리에서 집계에 반영되고, 새로고침해도 남아 있습니다(같은 브라우저 안에서만).

**데이터는 전부 예시입니다.** 방·질문·답변·닉네임 전부 이 데모를 위해 지어낸 것이며, 실제 상호나 실제 인물과 관련이 없습니다.

## 로컬에서 열어보기

빌드도, npm도, 서버도 필요 없습니다.

1. 이 폴더를 내려받거나 클론합니다.
2. `index.html`을 더블클릭해서 엽니다.

끝입니다. `file://`로 바로 열립니다.

## GitHub Pages로 올리기

1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더에서 순서대로:
   ```
   git remote add origin <저장소 주소>
   git push -u origin main
   ```
   (이 폴더는 이미 `git init`과 첫 커밋까지 되어 있습니다. 브랜치 이름이 `master`로 나오면 `git branch -M main`을 먼저 실행하세요.)
3. 저장소 Settings → Pages → Build and deployment에서 `Deploy from a branch`를 고르고, 브랜치는 `main`, 폴더는 `/(root)`로 둡니다.
4. 2~3분 기다린 뒤 발급된 주소로 들어갑니다.
5. **꼭 프라이빗(시크릿) 창에서 확인하세요.** 일반 창은 예전 캐시를 그대로 보여줄 수 있습니다.

## 시연 가이드

정해둔 경로입니다. 처음 보는 사람 앞에서 이 순서대로 눌러보면 됩니다.

1. `#/rooms`에서 업종 `필라테스`를 누릅니다.
2. 단계 `형태 정하기`를 누릅니다 — 방이 하나로 좁혀집니다.
3. 남은 방 하나로 들어갑니다.
4. 질문 `1인으로 갈지, 사람 두고 갈지`를 엽니다.
5. 답변 중 `접었어요`가 붙은 두 개를 가리킵니다 — 접은 사람 답도 똑같이 남아 있다는 걸 보여줍니다.
6. `내 조건과 같은 답만`을 켭니다 — 답 5개가 2개로 줄어드는 걸 보여줍니다.
7. 답을 하나 직접 남깁니다 — 조건별 정리 막대가 그 자리에서 늘어나는 걸 보여줍니다.
8. 새로고침(F5)합니다 — 방금 쓴 답이 그대로 남아 있는 걸 보여줍니다.

## 시연 전에 문구 고치기

아래 네 파일이 화면에 보이는 방·질문·답변·체크리스트 문구입니다.

- `js/11-seed-rooms.js`
- `js/12-seed-qa-core.js`
- `js/13-seed-qa-tail.js`
- `js/14-seed-checklist.js`

문구(텍스트)만 고치면 저장하고 새로고침하는 순간 바로 반영됩니다. 다만 **각 항목의 `id` 값은 절대 바꾸지 마세요.** id를 바꾸면 그 항목에 이미 쓰인 사용자 글이 부모를 잃고 조용히 사라집니다.

## 처음 상태로 되돌리기

`#/me` 화면 맨 아래에 `데모 처음 상태로` 버튼이 있습니다. 누르면 한 번 더 확인을 거쳐 지금까지 쓴 글을 지우고 시드 상태로 되돌립니다.

## 데이터는 어디에 있나요

전부 이 브라우저의 localStorage에만 저장됩니다. 서버도 로그인도 없고, 쓴 글이 밖으로 나가지 않습니다 — 다른 브라우저나 다른 기기에서 열면 처음 상태 그대로 보입니다.

바깥으로 나가는 요청은 글꼴(Pretendard CDN) 하나뿐입니다. 그마저 막혀도 시스템 글꼴로 떨어질 뿐 화면은 그대로 뜹니다.
